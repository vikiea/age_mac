Age Mac Privacy Policy

Effective date: May 18, 2026

Local Data

Age Mac 是本地优先的 macOS 加解密应用。它不会上传你的文件、密钥、密码、遥测数据、分析数据或操作历史。

应用会在本机处理你选择的文件、输出设置、操作历史和 age 密钥。查看或导出保存的私钥需要本机 macOS 验证。

Network Access

Age Mac 使用 Sparkle 检测更新。更新检查会读取公开的更新元数据：

https://vikiea.github.io/age_mac/appcast-arm64.xml
https://vikiea.github.io/age_mac/appcast-x86_64.xml

GitHub Pages 和网络基础设施可能接收到普通 Web 请求元数据，例如 IP 地址、User-Agent 和请求时间。Age Mac 不会把文件、密钥、密码或历史记录加入这些请求。
