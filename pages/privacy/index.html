Privacy policy

Your encryption workflow stays local.

Age Mac does not upload files, keys, passphrases, telemetry, analytics, or operation history.

Local data

Files and secrets stay on your Mac.

The app processes selected files, local settings, operation history, and age keys on this device. Saved private keys remain local in the macOS Keychain, and viewing or exporting them requires local macOS authentication.

Network access

Update checks read public metadata.

Age Mac uses Sparkle for update checks. Sparkle fetches public update metadata from:
https://vikiea.github.io/age_mac/appcast-arm64.xml
https://vikiea.github.io/age_mac/appcast-x86_64.xml

Web request metadata

The update request does not include your secrets.

GitHub Pages and network infrastructure may receive ordinary web request metadata such as IP address, User-Agent, and request time. Age Mac does not add files, keys, passphrases, or history to these requests.
