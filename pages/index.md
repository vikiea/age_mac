# Age Mac

Age Mac is a native macOS app for local age file encryption and decryption.

Current release: **1.5.0**

Published: **August 31, 2026**

- Universal DMG: [AgeMac-1.5.0-universal.dmg](https://github.com/vikiea/age_mac/releases/download/v1.5.0/AgeMac-1.5.0-universal.dmg)
- Apple Silicon DMG: [AgeMac-1.5.0-arm64.dmg](https://github.com/vikiea/age_mac/releases/download/v1.5.0/AgeMac-1.5.0-arm64.dmg)
- Intel DMG: [AgeMac-1.5.0-x86_64.dmg](https://github.com/vikiea/age_mac/releases/download/v1.5.0/AgeMac-1.5.0-x86_64.dmg)
- Repository: [github.com/vikiea/age_mac](https://github.com/vikiea/age_mac)
- Privacy policy: [Privacy](privacy/)
- Appcast: [Apple Silicon](appcast-arm64.xml), [Intel](appcast-x86_64.xml), [Universal](appcast.xml)
- License: [MIT](https://github.com/vikiea/age_mac/blob/main/LICENSE)

Age Mac keeps files, keys, passphrases, and history local to your Mac. Version 1.5.0 makes X25519 + ML-KEM-768 post-quantum hybrid keys the recommended default, preserves classic X25519 compatibility, and interoperates with the official age CLI. Update checks use Sparkle and read public metadata from this GitHub Pages site.
