# Age Mac

Age Mac is a native macOS app for local age file encryption and decryption.

Current release: **1.2**

Published: **May 21, 2026**

- Universal DMG: [AgeMac-1.2-universal.dmg](https://github.com/vikiea/age_mac/releases/download/v1.2/AgeMac-1.2-universal.dmg)
- Apple Silicon DMG: [AgeMac-1.2-arm64.dmg](https://github.com/vikiea/age_mac/releases/download/v1.2/AgeMac-1.2-arm64.dmg)
- Intel DMG: [AgeMac-1.2-x86_64.dmg](https://github.com/vikiea/age_mac/releases/download/v1.2/AgeMac-1.2-x86_64.dmg)
- Repository: [github.com/vikiea/age_mac](https://github.com/vikiea/age_mac)
- Privacy policy: [Privacy](privacy/)
- Appcast: [Apple Silicon](appcast-arm64.xml), [Intel](appcast-x86_64.xml), [Universal](appcast.xml)
- License: [MIT](https://github.com/vikiea/age_mac/blob/main/LICENSE)

Age Mac keeps files, keys, passphrases, and history local to your Mac. Update checks use Sparkle and read public metadata from this GitHub Pages site.
